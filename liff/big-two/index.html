怎麼玩？

4 人輪流出牌，牌型大小：單張 < 對子 < 三條 < 五張牌型（順子 < 同花 < 葫蘆 < 鐵支 < 同花順）。

基本規則：

  • 持有方塊 3 的人先出，且開局第一手一定要包含方塊 3
  • 接下來只能出「同類型、更大」的牌，或選擇跳過
  • 大家都跳過一輪後，最後出牌的人可以自由開新的一輪
  • 出完手牌名次最好，一直玩到只剩一人還有牌為止

缺人的座位開局時會自動由機器人補上，機器人只用簡單邏輯出牌，純粹是陪你湊一桌，不會刻意留牌算計。

每回合有 45 秒限時，超時系統會自動幫你出（跟機器人一樣的簡單邏輯），遊戲才不會卡住。

結束後依名次拿積分（第一名 3 分／第二名 2 分／第三名 1 分／第四名 0 分），輸入「大老二 排行」查看群組排行榜。
